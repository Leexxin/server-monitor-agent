# Contributing

1. Create a branch from `main`.
2. Keep changes focused and add tests for behavioral changes.
3. Run `make check` before opening a pull request.
4. Update documentation in the same commit as behavior changes. Follow `docs/maintenance.md` and keep `docs/README.md` and package documentation contents in sync.
5. Do not commit generated files from `dist/`; release artifacts belong in GitHub Releases.

All changes to `main` should go through a pull request after the initial repository bootstrap.
