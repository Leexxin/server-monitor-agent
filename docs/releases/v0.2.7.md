# SMA v0.2.7（Linux）

修复部分 iStoreOS/OpenWrt 镜像缺少 `od` 时，通用包安装到 Token 生成步骤报 `od: not found` 的问题。Token 仍以 `/dev/urandom` 的 32 字节随机数据为输入，先校验读取长度，再通过安装器本已依赖的 `sha256sum` 生成 64 位十六进制字符串。已有 Token 不会重置；Agent API 和鉴权格式不变。

使用分享根目录的固定一键入口重新运行即可，不需要手动删除上次失败留下的 `/opt/sma` 文件。完整命令见[自动安装](../automatic-installation.md)。

## 验证边界

CI 增加无 `od` 的生命周期测试，并继续执行 DEB、一键安装、通用包安装和重装测试。实际 iStoreOS 上的 procd 状态、开机自启、Token 展示及指标访问仍需用户重试验收。
