# SMA v0.2.6（Linux）

修复 iStoreOS/OpenWrt 缺少 `install` 工具时，通用包在复制首个文件前报 `install: not found` 的问题。一键安装器后续安装管理脚本的同类调用也已修复。改用 `mkdir`、`cp`、`chmod` 等 BusyBox 常见命令，保留 `/opt/sma` 的目录权限及原有配置和 Token。

通用包现在完成服务配置后才写入版本标记；同版本残缺安装会自动重试。无需手工清理失败安装。原有 v0.2.5 目录保持不变，发布 v0.2.6 后分享根目录的固定入口将自动选择新版本。

安装命令、`--show-token` 和日志位置见[一键安装](../automatic-installation.md)。本版不改变 Agent API 和 Token 格式。

## 验证边界

CI 检查运行时安装脚本不依赖 `install`，并在 Linux 临时环境验证通用包安装、重装、Token 保留和卸载；iStoreOS 实机仍需安装者执行一键命令并验证服务状态、开机自启及指标接口。
