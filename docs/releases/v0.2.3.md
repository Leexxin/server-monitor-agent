# SMA v0.2.3

本次主要补齐文档维护和排障交付，不改变指标 API、鉴权协议或已有 Token。

- 建立统一文档目录，新增 sma-center 无数据排障、维护发布规范及 Git 协作约定。
- 记录 Agent 地址第一段 IP 填错导致连接超时的案例，并区分服务运行、网络可达、鉴权成功和采集器健康。
- 更新原生安装示例；明确原生包管理器 purge 与 SMA 彻底卸载的边界。
- 所有安装包携带新增操作文档，Release 额外提供独立文档压缩包和 SHA-256。
- 发布说明与源码同版本管理，发布工作流读取本说明。

沿用 v0.2.2 的完整管理入口：`sma-ctl` 支持状态、诊断、启停、自启、日志、Token、监听配置、升级和卸载。已有 v0.2.2 用户不需要为了修正 sma-center 地址而升级 Agent；修正管理界面中的实际 Agent 地址即可。

验证门槛：Go 与脚本回归、双架构构建、Ubuntu AMD64 DEB 实机安装/鉴权/重装/服务管理/配置恢复/Token 更换/卸载。最终执行结果以该标签的 GitHub Actions 为准；RPM、APK、ARM64 的实际安装不在此实机测试范围内。

升级示例：`sudo sma-ctl upgrade`。升级沿用配置和 Token；服务会重启。安装日志：`/var/log/sma-install.log`。

文档入口：源码 `docs/README.md`，安装后 `/opt/sma/docs/README.md`，或 Release 的 `sma_0.2.3_docs.tar.gz`。
