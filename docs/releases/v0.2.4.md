# SMA v0.2.4（Linux）

## 变更

- iStoreOS/OpenWrt（procd）使用 x86_64 或 aarch64 Linux 通用包，安装到 `/opt/sma`，通过 `/etc/init.d/sma` 管理并设置开机自启。
- `sma-ctl` 支持 procd 的状态、启停、自启、日志、升级和卸载；已登录 root 的设备无需 `sudo`。
- 原有 systemd/OpenRC、DEB/RPM/APK 包选择与接口协议不变。

## 安装与验收

在 iStoreOS/OpenWrt 的 root shell 中下载并校验 `install-sma.sh`，然后运行 `sh install-sma.sh --show-token`。安装完成后执行 `/opt/sma/bin/sma-ctl doctor`、`/etc/init.d/sma enabled`、`/etc/init.d/sma status` 和 `curl -f http://127.0.0.1:9108/readyz`。若由 sma-center 远程访问，按 [生命周期文档](../lifecycle.md)修改监听地址并配置 Bearer Token。

支持的路由器架构仅 x86_64、aarch64；`/opt` 需可写且有足够空间。设备缺少用户管理工具时需要 `opkg` 可用及对应软件源，或预先安装 shadow 工具。发布 CI 的 Linux/DEB 测试和 procd 脚本模拟测试不能替代 iStoreOS/OpenWrt 实机安装、重启及卸载验收；该验收尚未完成。
