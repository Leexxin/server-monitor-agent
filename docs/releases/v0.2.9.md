# SMA v0.2.9（Linux）

修复 Ubuntu/Debian 与发行版仓库中的 `sma` 包重名导致监控代理可能被包管理器替换的问题。自本版起，DEB 包身份及文件名改为 `server-monitor-agent`；RPM、APK、通用包不变。

旧版监控代理请通过根目录 `install-sma.sh` 一键升级。安装器只在确认旧 `sma` DEB 拥有 `/opt/sma/bin/sma` 时才将其移除，避免误删 Ubuntu 的其他同名软件。直接 `apt install` 新 DEB 不会自动完成旧包迁移。若旧包已被替换，检查 `/opt/sma/config` 及备份，重新核对 sma-center 中的监听地址与 Bearer Token。

程序仍在 `/opt/sma`，服务仍为 `sma.service`；API、指标格式、默认监听地址、现有配置与 Token 均未变。升级后运行 `dpkg-query -W server-monitor-agent` 和 `sudo sma-ctl doctor` 验收。
