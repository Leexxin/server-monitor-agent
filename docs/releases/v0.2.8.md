# SMA v0.2.8（Linux）

`GET /v1/snapshot` 的顶层新增 `agentVersion`，自动发现的固定地址 `POST` 上报体也新增相同字段。值取当前运行 SMA 的构建版本，例如 `v0.2.8`。现有 `/version` 和 Prometheus `sma_build_info` 保持不变。

这是兼容性新增字段，`schemaVersion` 仍为 `v1`，已有字段和 Token 格式不变。接入系统应把 `agentVersion` 当作可缺失字段处理，以兼容尚未升级的 Agent。字段示例与语义见[指标接口](../api-integration.md)及[自动发现上报](../discovery-api-integration.md)。

## 验证边界

单元测试覆盖快照与上报体中的构建版本；发布流程继续执行 Linux 包安装和通用包生命周期测试。生产 Agent 升级与 sma-center 前端显示需在各自环境验收。
