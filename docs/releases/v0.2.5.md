# SMA v0.2.5（Linux）

本版规范 GOFTP 的版本目录和固定安装入口，不改变 Agent 指标、发现接口或 Token 格式。

## 部署方式

分享根目录只保留固定入口 `install-sma.sh`、对应的 `.sha256` 和 `latest.txt`；每个版本的校验清单、安装包与管理脚本放在不可变的 `vX.Y.Z/`。安装器从根目录读取目标版本，自动选择架构并进入版本目录。`--version X.Y.Z` 可指定旧版本，无需读取根目录索引。

Release 附 `sma_0.2.5_gofpt_share.tar.gz`；源码管理员运行 `sh scripts/deploy-share.sh 0.2.5` 即可校验并上传，先验证版本目录，最后更新 `latest.txt`。完整命令见[一键安装文档](../automatic-installation.md)。

## 验证边界

Linux/Windows CI、DEB 生命周期与分享目录生成校验在发布流程中执行。GOFTP 实际上传和 iStoreOS/OpenWrt 实机安装、重启、卸载属于独立部署验收；只有实际执行并成功后才算完成，不以 GitHub Release 成功代替。
